# DeskDetect — YOLOv8 Custom Object Detection

This project was developed as part of an Artificial Intelligence internship to explore the complete workflow of a custom object detection system, including dataset preparation, model training using Google Colab, performance evaluation, and interactive inference using a Gradio web application.

---

## 🎯 Selected Classes
The model was trained on a custom subset of the **COCO 2017** dataset focusing on 8 desktop/daily life classes:
1. `laptop`
2. `keyboard`
3. `mouse`
4. `cell phone`
5- `bottle`
